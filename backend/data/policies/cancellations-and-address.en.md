# Cancellations and address changes

## When you can cancel an order
An order can be cancelled only while it is in preparation (status "processing"). Once the order has been shipped, it can no longer be cancelled.

## When you can change the delivery address
The delivery address can be changed only while the order is in preparation. Once the order has been shipped, the address can no longer be changed.

## If the order has already shipped
If your order has already been shipped, you cannot cancel it or change its address. When it is delivered, you can return the items that do not suit you within 30 days, following the return policy.

## Who handles these requests
The assistant cannot modify an existing order. When you ask to cancel an order or change an address, the assistant passes your request to an advisor by creating a ticket. The advisor handles it and leaves a note when it is resolved.

## What to tell the assistant
Give your order number and the email address used for the order. For an address change, also give the new full delivery address. For a cancellation, say which order you want to cancel.

## Checking whether your order is still in preparation
Ask the assistant for the status of your order. If the status is "processing", your request can be sent to an advisor. If the order is already shipped, the assistant will explain that it is too late.

## Following your request
Ask the assistant for the status of your request. The status of the request is the status of its ticket: "open" while an advisor handles it, "resolved" once it is done.

## Refund after a cancellation
If an advisor cancels your order, the refund goes to your original payment method. For any question about a refund, see the refund policy or ask the assistant.

## Partial changes
The assistant cannot change items, sizes or quantities of an existing order. To get another size or colour of an item after delivery, see the exchange policy.
