# Returns

## Return deadline
You can return an item within 30 days after the delivery date of your order. The 30 days start on the day the parcel is delivered, not on the day you ordered. After 30 days, the return cannot be requested through the standard returns procedure.

## Condition required for a return
A returned item must be unworn, with its original tag still attached and in its original packaging. An item that has been worn, washed, altered or that has lost its tag cannot be returned. Check the item carefully before requesting a return.

## Items that cannot be returned
For hygiene reasons, underwear and swimwear cannot be returned, even if they are unworn and still in their packaging. This rule applies to every order, including sale items.

## No return before delivery
A return can only be requested once the order has been delivered. If your parcel has not arrived yet, you cannot create a return. If you no longer want the order, see the cancellation policy: an order can only be cancelled while it is still in preparation.

## Returning one item or several
Each return concerns one item of your order. If you ordered three items and want to send one back, you request a return for that item only. A return covers a whole order line: if you bought several units of the same item on one line, the return covers the whole line, not a part of the quantity. Only one return can exist for a given item.

## How to request a return
Tell the assistant which item you want to return. The assistant checks the return rules for that item (delivery date, deadline, type of item), then asks you to confirm. A return is created only after you explicitly confirm. You will need your order number and the email address used for the order.

## What happens after your request
Your return starts with the status "requested". An advisor reviews it and either approves or refuses it. You can ask the assistant at any time for the current status of your return.

## Return shipping
Returns are free. Once an advisor approves your return, a prepaid return label is sent to you by email. Pack the item in its original packaging, attach the label and drop off the parcel as indicated on the label. Do not send the item before the return is approved.

## If your return is refused
An advisor may refuse a return, for example if the item does not meet the conditions. If you disagree with the decision, tell the assistant: it will pass your case to an advisor who can review it.

## Refund after a return
Once the shop receives your returned item, the refund is processed to your original payment method. See the refund policy for timing.
