# Exchanges

## What an exchange is
An exchange means receiving the same item in another size or another colour, depending on stock. It is not possible to exchange an item for a different article. If you want a different article, return the item under the return policy and place a new order.

## Availability
An exchange depends on the stock available for the size or colour you want. An advisor checks the stock when handling your request. If the size or colour you want is not available, the advisor will tell you, and you can choose to return the item for a refund instead.

## How to request an exchange
The assistant does not create exchanges itself. When you ask for an exchange, the assistant passes your request to an advisor by creating a ticket. Give the assistant your order number, the item concerned and the size or colour you want.

## Conditions for an exchange
Exchanges follow the same conditions as returns: the item must be within 30 days after delivery, unworn, with its original tag and in its original packaging. Underwear and swimwear cannot be exchanged.

## No exchange before delivery
An exchange can only be requested after the order has been delivered. Before delivery, you can ask for a change only if the order is still in preparation, and only through the cancellation and address change policy.

## Who handles exchanges
Exchanges are handled by advisors, in the ticket queue. The assistant cannot ship parcels, change an order or update stock. The advisor leaves a note on the ticket when the case is resolved.

## Following your exchange request
Ask the assistant for the status of your request. The status of an exchange is the status of its ticket: "open" while an advisor is working on it, "resolved" once it is handled.

## Choosing the right size
If you hesitate between two sizes, see the size guide before requesting an exchange. In general, if you are between two sizes, choose the larger one.

## If you prefer a refund
If you would rather not exchange, you can return the item and be refunded to your original payment method, following the return and refund policies.
